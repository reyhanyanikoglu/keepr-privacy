# Keepr — Gizlilik ve Destek

Bu depo yalnızca Keepr uygulamasının gizlilik politikası ve destek sayfalarını
yayınlar. Uygulamanın kaynak kodu burada değildir.

| Sayfa              | Adres                                                     |
| ------------------ | --------------------------------------------------------- |
| Gizlilik Politikası | https://reyhanyanikoglu.github.io/keepr-privacy/          |
| Destek             | https://reyhanyanikoglu.github.io/keepr-privacy/support.html |

Uygulama yeni bir veri işlemeye başlarsa (ör. yedekleme, hesap, analiz) önce bu
sayfa güncellenir ve "Son güncelleme" tarihi değiştirilir.
